# KLIA Easy Move

Team 04 · **Travel With Confidence** — safe, accessible and family-friendly travel.

A one-page guide to getting out of KLIA Terminal 1 with confidence:

- **Route finder**: pick destination, who's travelling (kids, stroller, wheelchair, luggage, budget) and group size to get the best ride.
- **Terminal 1 map**: side view of Levels 5, 3 and 1 with the route drawn from the Arrival Hall exit.
- **Grab pickup guide**: Level 1, Door 3/4, step by step.
- **Ride comparison**: KLIA Ekspres, KLIA Transit, Grab, coupon taxi, bus, meter taxi, car rental.
- **Family & accessibility tips, safety rules, driver phrase card (Malay/English), ready-check list.**

Plain HTML, CSS and JavaScript in `index.html`. No build step.

## Run locally

Open `index.html` in a browser.

## Deploy to Vercel

Import this repo at https://vercel.com/new, keep Framework Preset = **Other**, no build command, and click **Deploy**.

Information is collected from Malaysia Airports (https://www.malaysiaairports.com.my/en/klia1) and public transport guides. Fares, doors and times can change; always follow airport signs.
